# Card

Cards group related content on a shared surface. Use them to present information, actions, or navigation in a scannable, contained layout.

Three variants are available: **contained** for flexible free-form content (four layout options), **open** for structured image + text + action layouts, and **open — horizontal** for wide promotional content.
