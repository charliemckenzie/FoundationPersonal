# Foundation DDS — Component Tracker

Track who is working on what, and where each component is in the pipeline.

**Board:** https://github.com/users/Paolo-Meyer_artghec/projects/2

---

## Accessing the board

1. Open the link above (you'll need a GitHub account)
2. If prompted, request access from Paolo
3. Switch to **Board view** using the view toggle in the top-right corner

---

## Columns

| Column | Means |
|---|---|
| **Todo** | Not started — available to pick up |
| **In Progress** | Actively being worked on |
| **Done** | Stable — signed off and published |

---

## Assigning yourself to a component

1. Find the component card on the board
2. Click the card to open it
3. Set the **Owner** field to your name (Paolo / Jade / Adam)
4. Move the card to **In Progress**

---

## Moving a card

Drag the card to the appropriate column as your work progresses:

```
Todo → In Progress → Done
```

Or click the card and change the **Status** field directly.

---

## Adding a new component

New components are synced from `docs/components.md`. If you add a component to that file, let Paolo know and he can run the sync script to add it to the board automatically.
