## Known limitations and usage constraints

- Do not use `reversed` on light or neutral surfaces; colour assumptions are inverted and can fail contrast.
- When an icon adds meaning not present in visible text (for example, opens in a new tab), provide `startIconLabel` or `endIconLabel`.
- Disabled buttons should include nearby explanatory text; do not rely on disabled state alone for guidance.
- Unsupported semantic colors are out of scope for this public Button report. If they become documented options, rerun the conformance review for them.

## Remediation and ownership

- Owner: Design System team
- Next review trigger: any token or theme change affecting button colours, focus ring, or sizing
- Status tracking: update this page and link issues in the component change log when gaps are found
