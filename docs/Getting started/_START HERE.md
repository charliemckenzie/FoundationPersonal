## Quick reference

**Run the project locally:**
```bash
npm install
npm run storybook       # component library
npm run dev             # Next.js app
```

**Verify your setup:**
```bash
npm run check-setup
```

**Need help?** Open Copilot Chat in VS Code and ask — or switch to **Sideshow Bob** if you want to plan work without touching code.
