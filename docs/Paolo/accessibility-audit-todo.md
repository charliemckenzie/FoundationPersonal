# Foundation — Accessibility Audit

Full WCAG 2.2 AA audit of Foundation design system (Theme A). Audit date: 2026-04-21. Report only — no changes made yet.

## FAILs — resolved ✓

- [x] **SC 1.4.11 — Accordion border contrast** — fixed 2026-04-21
  - `divider` + `border.default` moved from `neutral[300]` → `neutral[500]` (#64748b)
  - Light mode: 1.48:1 → 4.76:1 on white. Dark mode: 1.72:1 → 3.75:1 on neutral[900].
  - Also fixed in `generate-tokens.ts` and `tokens.json` regenerated.
  - Note: Accordion component still uses `palette.divider` directly — no component change needed, token fix is sufficient.

- [x] **SC 1.4.3 — Info button text contrast** — fixed 2026-04-21
  - `info.main` moved from `cyan[600]` (#0891b2) → `cyan[700]` (#0e7490)
  - 3.68:1 → 5.36:1 with white text. `info.dark` bumped to `cyan[800]` to maintain light/main/dark spread.

- [x] **SC 1.4.3 — Success button text contrast** — fixed 2026-04-21
  - `success.main` moved from `green[600]` (#059669) → `green[700]` (#047857)
  - 3.77:1 → 5.48:1 with white text. `success.dark` bumped to `green[800]` to maintain spread.

## WARNs — resolved ✓

- [x] **SC 4.1.2 — Modal without title has no accessible name** — fixed 2026-04-21
  - Added `ariaLabel?: string` prop to Modal; passed as `aria-label` on MuiDialog when no `title` is provided.
  - File: `src/components/Modal/index.tsx`

- [x] **SC 3.3.1 — Form errors not announced via live region** — fixed 2026-04-21
  - Added `role="alert"` on error `helperText` across all five form components.
  - TextField: via `slotProps.formHelperText: { role: 'alert' }` when `error=true`
  - Checkbox, Switch, Select, RadioGroup: `role={error ? 'alert' : undefined}` on FormHelperText

- [x] **SC 2.4.7 / 2.4.13 — Focus styling for Checkbox and Radio** — fixed 2026-04-21
  - Added explicit `&.Mui-focusVisible` outline overrides for MuiCheckbox and MuiRadio in `src/app/themes/factory.ts`.
  - Pattern matches existing IconButton overrides: 2px solid outline using component color, 2px offset.
  - MUI's OutlinedInput (TextField, Select) already applies a 2px border on focus — passes SC 2.4.13.

- [x] **SC 1.3.1 — Table column headers missing scope attribute** — fixed 2026-04-21
  - Added `component="th" scope="col"` to all header TableCell elements.
  - File: `src/components/Table/index.tsx`

- [x] **SC 1.3.1 — Badge has no accessible context** — fixed 2026-04-21
  - Added `ariaLabel?: string` prop; passed to `slotProps.badge` as `aria-label` when provided.
  - File: `src/components/Badge/index.tsx`

- [x] **SC 1.4.11 — Checkbox unchecked border contrast** — investigated, no fix needed
  - MUI's default unchecked checkbox uses `action.active` ≈ rgba(0,0,0,0.54) → #757575 on white = 4.60:1. Passes SC 1.4.11 (≥3:1).

## PASSes — no action needed

For reference — these were audited and confirmed compliant:

- Button: keyboard access, focus ring, loading state aria, disabled state (SC 1.4.3 exempt)
- Icon: `aria-hidden="true"` on decorative, `aria-label` on interactive
- IconButton: requires and enforces accessible label
- Modal (with title): DialogTitle wired to aria-labelledby
- Accordion: aria-controls / aria-expanded correct
- RadioGroup: fieldset + legend structure
- Select: labelId wired
- Spinner: `role="status"`, `aria-label="Loading"`
- Tooltip: pointer, keyboard, and focus triggers (SC 1.4.13 pass)
- text.primary on background.default: 17.1:1 (AAA)
- text.muted on background.default: 7.26:1 (AAA)
- Primary button (white on trueBlue[600]): 5.80:1 (AA pass)
- Warning button (neutral[900] on amber[400]): 9.78:1 (AAA)
- Dark mode text.primary: 19.3:1 (AAA)
- All interactive button target sizes ≥ 36px height (SC 2.5.8 pass)
