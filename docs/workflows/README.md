## How these docs are structured

Each guide documents a **working, tested outcome** — not a plan or a work-in-progress. If it's in here, it works.

Every guide covers:
- What the thing does and why it exists
- Step-by-step instructions to use it
- File locations and relevant code
- How to extend or modify it
