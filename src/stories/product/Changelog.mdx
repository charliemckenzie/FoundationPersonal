# Changelog

All notable changes to Foundation are documented here.

## Versioning rules

- **Patch** — bug fix, accessibility fix, docs update, or story added (e.g. v0.1.0 → v0.1.1)
- **Minor** — one or more components promoted to stable; new token additions; significant new docs (e.g. v0.1.0 → v0.2.0)
- **Major** — general availability (all planned components stable), or breaking changes requiring migration (e.g. v0.x → v1.0.0)

**If a feature shipped, the minor version goes up.** Patches are for everything else.
