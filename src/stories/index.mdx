# Component Library

This is the Foundation design system — a living component library built to support production-quality UX prototypes.

## How This Works

Every component goes through the full pipeline before it's marked **Stable**:

1. **Lenny** builds it
2. **Chalmers** reviews code quality
3. **Flanders** reviews accessibility (WCAG 2.2 AA)
4. **Marge** reviews visual consistency
5. **Lisa** writes this story and usage docs
6. **Frink** commits and opens a PR
7. **You** (the designer) approves and merges
