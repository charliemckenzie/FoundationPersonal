# Foundation

<VersionBadge />

A living component library built to support production-quality UX prototypes. Every component is reviewed for code quality, accessibility, and visual consistency before it's marked stable.

---

## [Component Status](/?path=/docs/foundation-component-status--docs)

37 components across draft, review, and stable stages. Use this page to find any component, check its current status, and jump to its story.

Stable components are fully signed off and safe to use in prototypes. Review components are with the specialist agents. Draft components are in progress and not yet reviewed.

---

## [Changelog](/?path=/docs/foundation-changelog--docs)

Version history from v0.1 (September 2024) to the current release. Each entry lists what was promoted to stable, what was added as draft, and any infrastructure or documentation changes that shipped with that version.

Versioning is feature-driven — the minor version increments whenever a component reaches stable.

## [Roadmap](/?path=/docs/foundation-roadmap--docs)

9 components are currently in the review cycle. 4 are planned for the next cycle once the current batch clears. 22 are in the backlog with no committed order.

The roadmap also tracks larger initiatives: dark mode, Figma Code Connect, composition patterns, and motion guidelines.

## [Accessibility](/?path=/docs/foundation-accessibility--docs)

WCAG 2.2 AA is the baseline for every component in Foundation, not a goal. This page documents the specific standards applied — colour contrast ratios, keyboard navigation requirements, focus management, ARIA usage, and the seven new criteria introduced in WCAG 2.2.

Flanders reviews every component against these standards before it can reach stable.

## The pipeline

Every component follows this sequence before it's marked stable.

1. **Moe** — Approves component structure and API. Nothing is built without this.
2. **Lenny** — Builds the component.
3. **Chalmers** — Code quality review: TypeScript, token usage, charter compliance.
4. **Flanders** — Accessibility review: WCAG 2.2 AA, keyboard nav, focus management.
5. **Marge** — Visual consistency: tokens, spacing, cohesion with the rest of the library.
6. **Lisa** — Writes the Storybook story and usage docs.
7. **Willie** — Runs the full sign-off checklist; updates component status.
8. **Frink** — Commits and opens a PR.
9. **You** — Reviews and merges.
